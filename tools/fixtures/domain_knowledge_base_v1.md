# 🏛️ KINTAI 勤怠・給与ドメイン知識ベース (Domain Knowledge Base v1.0)

> **対象ドメイン**: 日本型シフト・勤怠・給与精算システム (KINTAI)  
> **根拠法令**: 日本国労働基準法第37条（時間外、休日及び深夜の割増賃金）  
> **通達基準**: 昭和22年9月13日 発基第17号、平成11年3月31日 基発第168号、基発第150号（端数処理通達）

---

## 1. 労働基準法第37条 割増賃金算定基準

### 1.1 法定時間外労働（残業手当）
- **法定基準**: 1日8時間（480分）または週40時間を超える労働。
- **割増率**: 通常の労働時間の賃金の25%以上（1.25倍）。
- **除外時間**: 休憩時間は無給控除とし、実労働時間のみを対象とする。

### 1.2 深夜労働（深夜手当）
- **法定時間帯**: 午後10時（22:00:00）から翌日午前5時（05:00:00）まで。
  *(※ 労働基準監督署の特定命令がある地域・期間を除き、標準法定枠は 22:00 ~ 05:00)*
- **割増率**: 通常の労働時間の賃金の25%以上（1.25倍）。

### 1.3 重畳割増（残業 ＋ 深夜）
- **適用条件**: 1日8時間を超える法定時間外労働が、深夜時間帯（22:00 ~ 05:00）に行われた場合。
- **割増率**: 1.00（基本給） + 0.25（時間外） + 0.25（深夜） = **1.50倍（150%）**。

## 2. 端数処理基準（基発第150号）

1. **日別計算**: 1日ごとの労働時間・手当計算において、分単位で厳密に計算し、日別合算を行う。
2. **50銭基準**: 1か月における割増賃金の総額に1円未満の端数が生じた場合、50銭未満を切り捨て、50銭以上を1円に切り上げる（`RoundingMode.HALF_UP`）。
3. **1円齟齬防止 (Sum-First-Round-Last)**: 日々の端数を個別に四捨五入して合算すると誤差が累積するため、月次確定時に一括処理を行う。
