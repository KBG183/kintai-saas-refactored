## 1. 監査対象不変条件（Labor Law Invariants）

### ① 6段階法定割増率の完全性
- [ ] **所定時間外（法定外残業: 1日8時間または週40時間超）**: 基本時給の **+25%以上（1.25倍）** が適用されているか。
- [ ] **深夜労働（22:00 ~ 05:00）**: 基本時給の **+25%以上（1.25倍）** が適用されているか。
- [ ] **深夜残業（時間外かつ深夜の重複）**: 法定要件に基づき **+50%以上（1.50倍 = 25% + 25%）** が重畳適用されているか。
- [ ] **法定休日労働（週1日または4週4日の法定休日の労働）**: 基本時給の **+35%以上（1.35倍）** が適用されているか。
- [ ] **休日深夜労働（法定休日かつ深夜の重複）**: 基本時給の **+60%以上（1.60倍 = 35% + 25%）** が適用されているか。
- [ ] **月60時間超の時間外割増（大企業・中小企業共通）**: 月60時間を超える時間外労働に対して **+50%以上（1.50倍）**（深夜重複時は **+75%以上**）が正しく考慮されているか。

### ② 金額端数処理の法的基準（通達: 昭和63年3月14日基発150号）
- [ ] **1円未満の端数処理**: 50銭未満切捨て、50銭以上1円未満切上げ（四捨五入: `RoundingMode.HALF_UP`）が適用されているか。
- [ ] **計算順序**: 原則として「月間の総割増賃金額」に対して端数処理を行っているか（日ごとの過剰な切り捨て・切り上げによる労働者不利益の有無）。
- [ ] **浮動小数点型の完全排除**: 計算過程に `float` や `double` が混入せず、すべて `BigDecimal` または整数分・銭で処理されているか。

### ③ 時間集計の端数処理基準
- [ ] 1日単位の時間集計において、1分単位で計算されているか（日単位での切り捨ては違法）。
- [ ] 1か月単位の時間集計において、30分未満切捨て・30分以上1時間切上げの特例を適用する場合、合意および就業規則に合致しているか。
